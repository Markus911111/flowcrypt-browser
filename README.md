# 📱 FlowCrypt Android Tor Wrapper

Use FlowCrypt with .onion sites on Android — via Orbot (Tor)!

## ✅ Steps

- [ ] Install Orbot ([Play Store](https://play.google.com/store/apps/details?id=org.torproject.android))
- [ ] Start Orbot – tap the onion & wait for green!
- [ ] Open FlowCrypt Tor Wrapper app
- [ ] Enter a URL (.onion or regular)
- [ ] Tap LOAD — you're private via Tor!

## 🆘 Troubleshooting

- Can't connect? Orbot must be started!
- .onion not loading? Check spelling, try again.

## 📱 Testing
- Build app on Galaxy S24 or similar.
- Confirm Orbot is running.
- Load multiple .onion and normal URLs.
